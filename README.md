
Lathgate.gg

A lightweight, zero-dependency personal website and local network (LAN) hub featuring a single-file HTML/CSS/JS frontend, custom themes, a responsive UI, an editable guestbook, and a native Windows PowerShell system tray server.

Features, Project Structure, and Setup

Lathgate.gg is structured as a single-file application (lathgategg.htm) paired with a PowerShell .NET HttpListener system tray server (tray-server.ps1), a hidden-window launcher (Start lathgate.bat), and supporting assets. Key capabilities include zero external dependencies, 6 built-in customizable color themes, responsive mobile/desktop UI support, an editable local guestbook backed by /api/guestbook, and background system tray operation.
For the full feature breakdown, directory layout, Administrator Command Prompt configuration commands for port 80 and mDNS, and auto-start instructions, please refer to the project documentation on GitHub.
